# Code of conduct

This project is built for children and the volunteers who teach them, and we want working on it to feel
the same as a good dojo: welcoming, patient and safe, whatever your experience, background, gender,
disability or the language you're most comfortable in.

At the dojos themselves, the site's own [code of conduct](https://demo.coolestprojects.be/code-of-conduct/)
applies. This one is for the project: issues, pull requests, reviews and any other place we talk about it.

## What we expect

- Be kind and respectful, also when you disagree. Criticise code and ideas, never people.
- Assume good intent, and explain rather than dismiss: plenty of contributors are new to Django, to
  open source or to English.
- Help each other: asking a question and sharing what you know are both part of the work.
- Respect people's privacy. Never post anyone's personal data, and certainly not a child's, in an issue,
  a screenshot, a log or test data. Use the seeded demo data instead.

## Not acceptable

- Harassment, insults, discriminatory jokes or language, and sexualised content of any kind.
- Personal attacks, trolling, and repeatedly pushing a point after the maintainers decided.
- Publishing someone else's private information, or a security problem before it was fixed
  (see [`SECURITY.md`](SECURITY.md)).

## Reporting

Contact the maintainers privately at **erik@woidt.be**. We treat every report confidentially, and we'll
tell you what we did about it. If a child may be in danger, call 112 first.

## What happens

The maintainers decide what to do, from a private word to removing a comment or blocking someone from the
project, temporarily or for good. They apply this code to themselves as well.

This code borrows its ideas from the [Contributor Covenant](https://www.contributor-covenant.org/).
