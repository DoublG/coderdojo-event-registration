Promotions and the organisation's own events
=============================================

The organisation's own events
------------------------------

CoderDojo Belgium's own events (CoderDojo Girlz, Coolest Projects, ...) are
run from the **CoderDojo Belgium** dojo. It works like any dojo: its team
(a champion and mentors, each with a valid background check) creates the
events, publishes them and takes attendance from its dojo dashboard. The
difference is that it isn't a place families visit: it never shows in the
dojo finder and has no public dojo page, and its events say **Organised by
CoderDojo Belgium**. Families don't get the "new sessions at your dojo"
mail for these events; tell them with a campaign (see :doc:`campaigns`).

An event of this dojo can take registrations on another website: fill in
**Registration on another website** when you create or edit it, and leave
**Places** empty. Its page then links to that website instead of showing
the sign-up form. Such an event has no registrations or attendance on this
site, so it doesn't count in the children's attendance figures.

Promotions
-----------

A promotion features one event in one place on the public site, for a
while. Open **Promotions** in the organisation dashboard to see them,
grouped by place, and choose **New promotion** to add one.

There are four places:

- **Homepage: large card under the introduction**, the first thing
  visitors see.
- **Homepage: first in Upcoming sessions**, before the sessions in date
  order, with a **Featured** label.
- **Events page: pinned above the list**, shown when nobody has searched.
- **Dojo finder: banner above the results**, on the dojo finder page
  (**Dojos**). Not on the homepage's small dojo finder: the homepage
  already features events higher up.

For each promotion you choose:

- **Event**: any upcoming event, of any dojo. A draft event can be picked;
  the promotion only shows once the event is published.
- **Show from** and **Show until**: when it shows. Leave **Show until**
  empty to stop when the event starts. A promotion never shows after its
  event has ended.
- **Rank**: the order within a place, lowest first. To reorder, change the
  ranks.
- **Title**, **Short pitch** and **Image** (all optional): replace the
  event's name and banner, and add a line of text.
- **In Nederlands** and **In Français** (optional): the title and pitch in
  those languages. Visitors see the version in their own language, else
  the English one.

The list shows each promotion's status: **Showing**, **Scheduled** (it
starts later), **Event not public** (the event is still a draft, or its
dojo isn't active) or **Ended**. Open a promotion to change it or to
remove it.

A promotion only changes where an event is shown, never who can sign up.
To reach people by mail as well, send a campaign that links to the event.
