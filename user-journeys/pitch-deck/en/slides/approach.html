Approach

Proven technology, a documented way of working

The stack

  • Django 6.1 on Python 3.14, MySQL with maps
  • Server-rendered pages with htmx, no app to install
  • Celery workers send every mail from a queue
  • Live notifications over WebSockets

The way of working

  • Design system first, every page built on it
  • Built with Claude Code as a pair programmer
  • Every feature ships with tests and documentation
  • Data model, conventions and help centre in the repo
DATA_MODEL.md explains the model and every design decision; CLAUDE.md the conventions; the help centre has 31 pages in three languages.
