Aanpak

Beproefde technologie, een gedocumenteerde werkwijze

De technologie

  • Django 6.1 op Python 3.14, MySQL met kaarten
  • Pagina's van de server met htmx, geen app nodig
  • Celery-workers versturen elke mail vanuit een wachtrij
  • Live meldingen via WebSockets

De werkwijze

  • Eerst het designsysteem, elke pagina erop gebouwd
  • Gebouwd met Claude Code als programmeerpartner
  • Elke functie komt met tests en documentatie
  • Datamodel, afspraken en helpcentrum in de repository
DATA_MODEL.md legt het model en elke ontwerpkeuze uit; CLAUDE.md de afspraken; het helpcentrum telt 35 pagina's in drie talen.
